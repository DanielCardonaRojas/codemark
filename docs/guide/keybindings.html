Keybindings & the Dashboard ​

Codemark ships a native, keyboard-driven dashboard (codemark tui) in the style of lazygit. It's a two-pane browser: a left sidebar (40%) with search, context, filters, and content; and a right main pane (60%) with an overview, steps, a code preview, and details.

Requires a Nerd Font — the dashboard uses glyph icons throughout.

Layout ​

Each pane is a TabbedPanel; switch its tabs with [ / ]. The left content panel has three tabs (Bookmarks / Collections / Tours); the right has a steps panel (Steps / Info / Query) and a details panel (Details / Comments).

Opening a collection or layout on launch ​

codemark tui accepts startup flags so you (or an agent, or a script) can jump straight to the right place instead of navigating there:

bash
codemark tui --collection login-flow                  # enter a collection's steps
codemark tui --layout code                            # start in a layout
codemark tui -c login-flow -l code                    # this collection, this layout

--collection/-c takes the exact collection name and opens it exactly as selecting it on the Collections tab and pressing Enter would. If no collection by that name exists, the dashboard opens normally and shows an error toast.

--layout/-l picks one of the pane arrangements you can otherwise reach with + / -:

LayoutWhat you see
defaultSidebar and preview side by side
listThe content list at full width
previewCode, pager and details at full width
codeCode and pager only, at full width
detailsThe details pane (notes, comments) full screen

Run codemark tui --help for the full list.

Commenting in the code preview ​

Comments are anchored to the code they talk about and shown inline, under that code.

KeyAction
cComment on the code under the cursor: the selected range, else the node at the cursor column, else the whole line
vStart (or end) a range selection, as in vim; Esc ends it
EnterToggle the column cursor without selecting
h / l, j / kMove the column cursor; with v, extend the selection
w / b / eNext word / previous word / end of word (column cursor only)
0 / ^ / $Line start / first non-blank / last character (column cursor only)
rReply to the comment the cursor is on
z / ZFold the comment under the cursor / fold all comments
n / NNext / previous comment

Selecting with v gives the most precise anchor: the comment points at the smallest node covering the selection. The selection must stay inside the bookmark's enclosing function, method or class.

Search ​

Press s (or Enter in the search bar) to search. The search bar shows a [ FTS | Sem ] segmented control. Toggle modes with Ctrl+S (semantic builds only). A Braille spinner indicates while semantic search runs; results are capped at 20.

  • FTS — substring search across notes, context, tags, and file paths.
  • Sem — semantic search by meaning (local vector embeddings).

Esc clears the query and drops any in-flight results.

Copying and moving collections between branches ​

c (copy) and m (move) on the Collections tab open a branch picker, the TUI version of codemark tour copy / tour move:

  • Type to filter branches. Substring matches rank first, then subsequence matches (qsc finds query-summary-cleanup). ↑/↓ or Ctrl+P/Ctrl+N move the selection, Ctrl+U clears the filter, Esc cancels.
  • Common branches are pinned under Common: the default branch (origin/HEAD), main/master/develop/dev/trunk, and the current branch. With an empty filter, Enter picks the detected default branch (origin/HEAD, else main, else master). If that isn't the branch you want, type its name or move the selection first. Remote-only branches are listed by their short name.
  • The collection is planned against the branch's committed tip. If nothing matches (or the branch can't be read), a notification says why and nothing is written. Otherwise a confirmation dialog shows how many steps match and which ones will be left out. Their bookmarks are kept.
  • A copy is named <collection>-<branch>, with -2, -3… added if that name is taken.

Overlays ​

  • ? Help — a context-aware cheat-sheet of the keys relevant to your current focus, with priority bands (pinned actions always show).
  • , Settings — a modal with three tabs: Configuration (paths, db, model, theme), Theme (live-preview and persist), and About. Navigate with j/k, switch tabs with [/], save with Enter, close with Esc or , (closing without saving reverts the theme).

Mouse support ​

Click to focus and select list items; scroll to navigate panes. Confirm dialogs (d deletes) also respond to mouse.
